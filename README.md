# Goldentime — 라이브 데모 (공개 프론트엔드)

**골든타임(Goldentime)** · AI 보이스피싱 피해회복 코파일럿
회사: **아비터(Arbiter)** · 대표 강다연

보이스피싱 피해 **직후 30분(골든타임)**에 피해자와 가족을 7단계 회복 절차로 안내하고,
은행·보험 인입용 구조화 리포트 패킷을 생성하는 사기대응 SaaS의 **공개 데모 프론트엔드**입니다.

## 라이브 데모
| 화면 | 대상 | URL |
|---|---|---|
| 은행 담당자용 관제 콘솔 | B2B | https://goldentime-console.dayeon603.workers.dev |
| 고객 화면 · 은행 앱 임베드 | B2B2C | https://goldentime-console.dayeon603.workers.dev/app |

## 이 저장소 구성
- `index.html` — 은행 관제 콘솔 (대시보드 · 사건 관제 · 리포트 패킷 · 감사 로그 · 데이터·출처)
- `app.html` — 고객(피해자)용 7단계 회복 가이드 (은행 앱 임베드 뷰)
- 의존성 없는 **자체완결 정적 파일**. Cloudflare Workers로 배포됩니다.

## 설계 원칙
- **결정론 우선.** 지급정지 번호 · 위험점수 · 긴급도 · 법적 절차는 전부 **결정론 규칙**으로 산출합니다.
  LLM은 피해자 진술 해석과 안내문 생성에만 관여하며 금액 · 번호 · 법적 판단에는 개입하지 않습니다.
- **개인정보 보호.** 데모의 모든 데이터는 **합성 · 마스킹** 처리된 예시이며 실제 개인정보를 포함하지 않습니다.

## 비공개 코드 안내 (Private)
운영 **백엔드 엔진**과 데이터셋은 **개인정보 보호 및 보안상의 이유로 비공개 저장소에서 관리**합니다.
이 공개 저장소에는 게시 가능한 **데모 프론트엔드만** 포함됩니다.

비공개 저장소에 포함된 항목:
- FastAPI(Python 3.12) 백엔드 — 라이브 엔드포인트 `/triage` `/risk` `/notify/family` `/report/packet`
- **485개 테스트** 통과 (기능 · 보안 · 퍼징 · 공격 매트릭스)
- HMAC 변조감지 감사체인(fail-closed) · PII 해시+마스킹 · 테넌트 격리 · 레이트리밋
- 사기 수취계좌 · 기관 연락처 검증 데이터셋 (경찰청 · 금감원 · 은행연합회 등 공식 출처)
